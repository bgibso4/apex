Session detail · reference build

Everything locked in Session Detail Explorations (turns 1 to 13), on one working phone. Read the session, then ••• › Edit session. In edit: tap any number (number pad, the value starts selected), tap a note (text keyboard), open Date, Start or Duration, swipe a set left and tap its trash to delete it (Undo in the toast), Add set, the trash to remove an exercise, Add exercise, tick protocols. Done is grey until something changes; it saves back to the read page, which recalculates. Close with changes asks to discard. ••• › Delete session asks to confirm.
