# Repo Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the React Native app out of the repo root into `apex-rn/` so the native app can live beside it in `apex-ios/`, with nothing shared but the root.

**Architecture:** Every tracked React Native path moves with `git mv`, so history follows. The root keeps only what both sides share: a pointer `CLAUDE.md`, `.github/`, `workers/`, `docs/`, `PRIVACY.md` and a generic `.gitignore`. CI for the React Native app runs from its folder and only when its folder changes.

**Tech Stack:** git, npm, Expo SDK 58, Jest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-27-ios-agentic-foundations-design.html` (section "Repo layout", and build-order step 1). This is plan 1 of 5 for that spec; plans 2 to 5 (iOS skeleton and hooks, design import and tokens, the first screen with the test tooling, iOS CI) are each written when the one before it has merged.

## Global Constraints

- The React Native app is frozen. This plan changes no file under `app/`, `src/`, `__tests__/`, `__mocks__/`, `assets/`, `modules/` or `plugins/` except by moving it.
- Folder name is exactly `apex-rn/`.
- `workers/`, `docs/` and `PRIVACY.md` stay at the root, unchanged.
- Tracked files move with `git mv`.
- From `.claude/`, nothing is committed in this plan.
- The root `CLAUDE.md` holds no rules of its own, only pointers.
- No em dashes in new prose; middots as separators.
- Pushing, opening the pull request and merging on green CI are approved for this effort (Ben, 2026-11-27). Merge with a merge commit and delete the branch.

## Review Focus

1. **A clone with no leftover root `node_modules`.** `npm ci` inside `apex-rn/` must work alone. Pinned by Task 3 (CI installs from scratch in `apex-rn/`).
2. **The generated native folder.** After a prebuild, `apex-rn/ios/` must be ignored while `apex-rn/modules/icloud-backup/ios/` stays tracked. Pinned by Task 1 step 6.
3. **The Worker.** `workers/health-api` must install and test exactly as before. Pinned by Task 1 step 7.
4. **A pull request that touches no React Native file.** It must be mergeable with no React Native checks. `main`'s protection has no required check names (verified 2026-11-27: `contexts: []`), so a path-filtered workflow blocks nothing. Pinned by Task 3 step 3.
5. **The local Expo module and config plugin.** `app.json` names `./plugins/withICloudBackup`, and Expo autolinks `./modules`. Both are relative to the project folder and move with it. Pinned by Task 4 (clean prebuild and simulator build).
