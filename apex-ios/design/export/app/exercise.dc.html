What works
  • Range chips; drag the graph (snaps to a PR within 6pt; the block or program lights up and its strip segment is outlined). Program has no PR, so its best line is dashed.
  • "What is est. 1RM?" opens in place.
  • Rep records: tap a row to open the session that set that record, scrolled to Back Squat; Show all opens the Rep records page, where the All reps menu filters History and each History row opens the session that set that record.
  • Sessions: tap a row, or Show all then a row; Session detail opens scrolled to Back Squat. Back returns where you were.
  • ••• at the top right opens Edit exercise (a short sheet): the body part pills toggle and update the line under the title. Tap Name or Note and the sheet rises to full height with the keyboard, so every field stays above it (typing is not wired; Done on the keyboard bar puts it away).
  • Resources: press and hold a row for Edit link / Remove (Undo for 3s). The hint goes after your first hold.
Add link
  • Opens as the short sheet, no keyboard until you tap a field (locked).
  • Paste drops in a sample link and fetches it for about a second (spinner in the thumbnail). Press Paste again for the next sample: a YouTube link (everything), an Instagram link (title, no picture), then three that return nothing: Instagram ("Instagram reel"), TikTok ("TikTok video") and an ordinary website (its address).
  • Tap ✓ before the fetch finishes and the row lands with its address, then fades to the real title.
Not wired: typing on the keyboard (it is a picture), opening a link, the other tabs, Session detail's own menu. The pushes are stand-ins for the system's.
