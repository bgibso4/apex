# Which simulator test classes a changed path can affect (read by scripts/affected-tests.sh, `make affected`).
# Paths are relative to apex-ios/. A change outside apex-ios/ affects nothing.
#
#   <path prefix> <Class> ...   a changed path under the prefix runs those classes
#   <path prefix> ALL           runs every simulator test (shared code)
#   <path prefix> NONE          runs nothing (cannot affect the simulator tests)
#
# A path takes the union of every rule whose prefix matches; "*.md" matches Markdown anywhere. A path no rule
# matches runs everything, so a gap here costs time, never coverage. Test files need no rule: a file under UITests/
# or SnapshotTests/ runs the *Tests classes it declares or extends, and SnapshotTests/__Snapshots__/<Class>/ runs
# <Class>. A new screen adds its rows here; `make ci-checks` fails while a test class is missing from this file.
