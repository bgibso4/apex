New in this demo, needs your call
The card's big blue number now carries a two-letter label, Hold or Rest, because a bare countdown can no longer say which one it is. 14a drew it bare.
A running set is the only place in the app where a number changes without you touching it, so the row numeral mirrors the clock rather than showing something different.
Only one set can run at a time. While one is going, the sets below it go fully dim: no blue ▶, no bright numeral, nothing to tap. Stopping the running set is what arms the next one.
Tapping a logged time still opens the wheel sheet, now min and sec. The seconds wheel moves in 5 second notches from whatever the timer recorded, so a correction never rounds your logged time behind your back.
